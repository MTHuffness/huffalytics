# Huffalytics

The public face of the NFL bets engine: this week's slate with the engine's
projected scores, last week's finals against their closing lines, the
engine's graded record, and team rankings entering the week.

Every file here is written by the Django app on the Mac at the end of an
NFL data sync (`manage.py publish_huffalytics`) and pushed; GitHub Pages
serves it at https://huffalytics.com. Nothing is edited by hand.
